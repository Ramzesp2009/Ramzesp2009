## 🏋️ Ram's Gym — my main project

**A strength-training diary for Android that plans your progress from what you actually lifted.**

- **Load cycles** — percent-based and wave periodization; the plan reads where you stand from the weights you lifted, not from a workout counter
- **Smart helpers** — rest timer computed from the last set, warm-up ramps, a recovery model, heart rate from any Bluetooth chest strap
- **Analysis and records** — program checks against your goal, per-exercise history, all-time records by muscle group
- **Social** — friends, a shared feed, likes, comments and push notifications
- **Offline first** — all training data lives on the phone; English and Ukrainian

**Under the hood:** Kotlin · Jetpack Compose · MVVM · Hilt · Room (60+ versioned migrations, each one tested) · Navigation Compose · DataStore · Coroutines & Flow · Supabase (Auth, Postgres with RLS, Storage, Edge Functions) · Firebase Cloud Messaging · Bluetooth LE · AlarmManager · R8 · JUnit and Compose UI tests
